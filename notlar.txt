=== Hafta 1 - Linux Komutları ===
pwd   : Bulunduğum dizinin tam yolunu gösterir.
ls    : Dizindeki dosya ve klasörleri listeler.
cd    : Başka bir dizine geçmemi sağlar.
mkdir : Yeni bir klasör oluşturur.
touch : Boş bir dosya oluşturur.

=== Hafta 2 - Git Komutları ===
git init   : Bulunduğum klasörü yeni bir Git reposuna dönüştürür.
git add    : Değişiklikleri staging area'ya ekler.
git commit : Staging'deki değişiklikleri kalıcı olarak geçmişe kaydeder.
git status : Dosyaların durumunu (untracked, modified, staged) gösterir.
git log    : Commit geçmişini listeler.
